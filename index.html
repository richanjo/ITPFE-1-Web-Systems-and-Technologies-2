Final Project Deadline: Dec 23, 2026 · 11:59 PM (PHT)

Final Project – Laravel-Based Web Management System

ITPFE 1 – Web Systems and Technologies 2 · Build upon your ITPE 130 – Integrative Programming and Technologies 2 final project using the Laravel Framework.

Project Description

Students will transform their previously developed final project in ITPE 130 – Integrative Programming and Technologies 2 into a fully functional web-based management system using the Laravel Framework.

The project must demonstrate the application of Laravel concepts and techniques discussed in the subject, particularly routing, controllers, models, views, database integration, CRUD operations, and other relevant framework functionalities.

TASK PROMPT

  1. Group Formation: Each group must consist of five (5-6) members.
  2. Organization Selection: Each group must select an organization, institution, or private company as the intended client or beneficiary of their proposed web application.
  3. System Development: Each group must transform its previous ITPE 130 final project into a Laravel-based web management system. The application must address an actual organizational or business need and implement functional management features. A simple static website is not acceptable.
  4. System Requirements: The web application must demonstrate appropriate database integration, CRUD operations, and relevant management functionalities based on the selected organization's requirements. The implementation must utilize the Laravel Framework.
  5. System Screenshots Submission: Each group must upload screenshots of their developed web application to document its implemented features and functionalities. The screenshots must clearly demonstrate the system's user interface, database-driven features, CRUD operations, and other relevant management modules. The final deadline for uploading the screenshots is December 23, 2026.
  6. Project Defense: Each group will be assigned a schedule for its final project presentation and defense on December 21, 2026. All members must participate in presenting and explaining their respective contributions to the project.
  7. Evaluation: Each web application will be evaluated based on the assessment rubric provided by the instructor.
