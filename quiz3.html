Primer: Understanding Eloquent Active Record Operations and Pagination in Laravel

1. Retrieving Records Using Eloquent

Laravel Eloquent provides methods for retrieving records from database tables:

  • all() – Retrieves all records from a model's corresponding table.
  • find($id) – Retrieves a record using its primary key.
  • where() – Adds conditions to a database query.
  • get() – Executes a query and retrieves the matching records.

Example:

$users = User::all();

$user = User::find(1);

$activeUsers = User::where('status', 'active')->get();

2. Creating Records

Eloquent provides two common ways to create and save records:

  • save() – Saves a newly instantiated model or persists changes to an existing model.
  • create() – Creates and saves a new model using an array of attributes in one operation.

Example using save():

$user = new User();
$user->name = 'John Doe';
$user->email = 'john@example.com';
$user->save();

Example using create():

User::create([
    'name' => 'John Doe',
    'email' => 'john@example.com'
]);

Mass Assignment and $fillable

The $fillable property defines which model attributes are allowed for mass assignment when using methods such as create().

protected $fillable = [
    'name',
    'email'
];

This helps protect the application against unauthorized mass assignment of model attributes.

3. Updating Records

Eloquent supports updating records by retrieving a model, modifying its attributes, and saving the changes.

$user = User::find(1);
$user->name = 'Jane Doe';
$user->save();

You can also update multiple matching records directly through an Eloquent query:

User::where('status', 'inactive')
    ->update(['status' => 'active']);

4. Deleting Records

Eloquent provides methods for deleting records:

  • delete() – Deletes a retrieved model instance.
  • destroy() – Deletes records using their primary keys without requiring the caller to retrieve each model instance first.

Example using delete():

$user = User::find(1);
$user->delete();

Example using destroy():

User::destroy(1);

Soft Deletes

Laravel supports soft deletion through the SoftDeletes trait. Instead of permanently removing a record, Laravel marks it as deleted by setting its deleted_at timestamp.

use Illuminate\Database\Eloquent\SoftDeletes;

class User extends Model
{
    use SoftDeletes;
}

This allows applications to retain deleted records and potentially restore them later.

5. Pagination in Laravel

Pagination divides large sets of database records into smaller pages, making information easier to browse and improving the user experience.

Common pagination methods include:

  • paginate() – Retrieves records with numbered page navigation.
  • simplePaginate() – Provides Previous and Next navigation without calculating the total number of records.

Example in a controller:

public function index()
{
    $users = User::paginate(10);

    return view('users.index', compact('users'));
}

The value 10 specifies the number of records displayed per page.

Example in a Blade view:

@foreach ($users as $user)
    <p>{{ $user->name }}</p>
@endforeach

{{ $users->links() }}

The links() method generates the HTML pagination navigation links.

For Previous and Next navigation only:

$users = User::simplePaginate(10);
